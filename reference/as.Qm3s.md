# Coerce [data.frame](https://rdrr.io/r/base/data.frame.html) or content of a [data.frame](https://rdrr.io/r/base/data.frame.html) into a *Qm3s* object ready for plotting

Coerce [data.frame](https://rdrr.io/r/base/data.frame.html) or content
of a [data.frame](https://rdrr.io/r/base/data.frame.html) into a *Qm3s*
object ready for plotting

## Usage

``` r
as.Qm3s(...)
```

## Arguments

- ...:

  A [data.frame](https://rdrr.io/r/base/data.frame.html) for a single
  argument, or the arguments of function
  [data.frame](https://rdrr.io/r/base/data.frame.html)

## Value

A [data.frame](https://rdrr.io/r/base/data.frame.html) of class *Qm3s*
