# RunModel function for both **airGR** InputsModel and GRiwrmInputsModel object

RunModel function for both **airGR** InputsModel and GRiwrmInputsModel
object

## Usage

``` r
RunModel(x, ...)
```

## Arguments

- x:

  \[object of class *InputsModel* or *GRiwrmInputsModel*\] see
  [CreateInputsModel](https://inrae.github.io/airGRiwrm/dev/reference/CreateInputsModel.md)
  for details

- ...:

  further arguments passed to or from other methods

## Value

Either a [list](https://rdrr.io/r/base/list.html) of OutputsModel object
(for GRiwrmInputsModel) or an OutputsModel object (for InputsModel)
